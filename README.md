# Game
    Tên: Nguyễn Tường Duy
    Mã sinh viên: 24021450

    Chủ đề game là tower defense. Người chơi sẽ đặt tháp súng để chiến đấu với kẻ địch.

    Giới thiệu ngắn gọn về tháp súng:
    - Tháp súng 1 bắn đạn bình thường
    - Tháp súng 2 bắn đạn đẩy lùi
    - Tháp súng 3 bắn 4 viên đạn bình thường

    Giới thiệu ngắn gọn về kẻ địch:
    - Hình tròn: không có gì đặc biệt
    - Hình thoi: chạy nhanh hơn
    - Hình vuông: có 2 mạng

    Tham khảo:
